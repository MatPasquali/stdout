### [Streaming Multi-Agent Autoregressive Diffusion Model with World State Registers](https://arxiv.org/abs/2607.21594v1)
`arXiv`

A team of researchers has introduced WorldWeaver (W^2), a streaming multi-agent autoregressive diffusion model that aims to address the issue of maintaining consistent world states in interactive multi-agent environments. This matters because existing models struggle to maintain shared states due to the complexity of managing multiple agents and views. WorldWeaver uses world state registers, which are learnable tokens that store shared world information and update dynamically after each generated chunk. These registers are trained with supervision signals that span individual agent status, global state views, and scene text, allowing for more effective state tracking and management.
