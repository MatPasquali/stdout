Twins: Learn to Predict Unified Representations with Focal Loss

This is important because it allows for a more integrated approach to visual information processing. The Twins model forms a unified continuous token space by concatenating ViT (Vision Transformer) and VAE (Variational Autoencoder) features on a shared token grid. However, the researchers encountered an optimization imbalance when modeling the Twins in a Diffusion Transformer, where the model fits the ViT component well but struggles to match the VAE latent distribution.
