TokTier: Exact Stateful Tokenization for Agentic LLM Serving

Pesquisadores desenvolveram o TokTier, um serviço de tokenização estatal que visa melhorar a eficiência dos sistemas de servidores de modelos de linguagem grande (LLM), que são usados em aplicações de inteligência artificial. CodeShrink: Adaptive Visual Compression for Efficient Multimodal Code Understanding

Pesquisadores desenvolveram o CodeShrink, uma estrutura de compressão visual adaptativa para melhorar a eficiência dos modelos de linguagem multimodais em entender códigos-fonte, o que é importante porque reduz os custos de processamento de grandes modelos de linguagem, tornando-os mais acessíveis.
