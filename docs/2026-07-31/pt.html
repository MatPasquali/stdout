ReToken: One Token to Improve Vision-Language Models for Visual Retrieval

Pesquisadores apresentaram o ReToken, uma abordagem inovadora para melhorar a eficiência dos modelos de visão-linguagem em tarefas de recuperação visual, um desafio que surge devido ao grande contexto visual que degrada o desempenho à medida que o número de elementos distraídos aumenta, e o processamento de todos os tokens de uma vez é inviável devido às limitações de memória da GPU. O ReToken é um único embeddimento aprendível treinado como um alvo de recuperação explícito que selecciona um conjunto sparso de tokens visuais relevantes para a consulta a partir de um cache de KV visual preenchido. Com uma arquitetura leve, o ReToken foi treinado em um pequeno conjunto de dados de perguntas e respostas sobre imagens e alcançou ganhos consistentes em benchmarks de imagem e vídeo.
