ReToken: One Token to Improve Vision-Language Models for Visual Retrieval

Researchers have introduced ReToken, a novel approach to improving the efficiency of vision-language models in visual retrieval tasks, a challenge that arises from the long visual context that degrades performance as the number of distractors grows, and processing all tokens at once is computationally infeasible due to GPU memory constraints. ReToken is a single learnable embedding trained as an explicit retrieval target that selects a sparse set of query-relevant visual tokens from a pre-filled visual key-value cache. With a lightweight design, ReToken was trained on a small image-question answering dataset and achieved consistent gains across image and video benchmarks.
