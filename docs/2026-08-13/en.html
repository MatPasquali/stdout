DreamFly: Causal Memory and Receding-Horizon Diffusion Planning for Aerial Vision-Language Navigation

DreamFly introduces a causally aligned historical memory, which enhances the current visual representation using only observations preceding the current decision step, allowing for temporal reasoning without future information leakage. This is particularly important because aerial navigation requires long-term planning and adaptation to unpredictable situations. With DreamFly, researchers aim to improve the ability of agents to make informed decisions in complex environments.
