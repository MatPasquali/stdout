PAIChecker: Uncovering and Checking PR-Issue Misalignment in SWE-Bench-Like Benchmarks

Researchers have found that software benchmarks, such as SWE-bench, which are used to evaluate the issue resolution capability of language models, often contain misaligned pairs of pull requests (PR) and issues, leading to inaccurate results. This occurs because the construction of these benchmarks typically involves extracting issue references from PR descriptions, with the issue description used as the problem statement, and the PR patch serving as the test oracle.
