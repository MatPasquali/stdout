RP-OPSD: Reasoning-Pivot-Guided On-Policy Self-Distillation for Multilingual Reasoning Transfer

Researchers have proposed a new method called RP-OPSD, which aims to improve the ability of large language models (LLMs) to perform reasoning in multiple languages, a crucial step in expanding reasoning capabilities beyond high-resource languages. This method is based on an on-policy self-distillation (OPSD) approach, which provides token-level supervision for student-generated iterations, and focuses distillation on key reasoning points. By doing so, language models can be trained to generate text and make decisions that advance or redirect the reasoning process, which is essential for cross-lingual reasoning transfer.
