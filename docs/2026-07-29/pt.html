Desktop-Delta Bench: Do Computer-Use Models Understand Desktop GUI Transitions?

Essa ferramenta pode ajudar a melhorar a compreensão dos modelos de uso de computador.

UniMem: Complementary Episodic-to-Parametric Memory for Boundary-Agnostic Task Streams

Com essa abordagem, os agentes LLM podem internalizar padrões de execução recorrentes e reduzir a sobrecarga de inferência no tempo de execução.

Empirical Evaluation of Out-Of-Distribution Performance of Tabular Foundation Models

Pesquisadores publicaram uma avaliação empírica do desempenho de modelos fundamentais de tabelas fora do conjunto de dados de treinamento, o que é importante porque esses modelos são cada vez mais usados para tarefas de previsão em dados tabulares, mas sua robustez em cenários reais é comprometida por mudanças na distribuição dos dados. Os modelos fundamentais de tabelas, ou TFMs, são treinados e avaliados em dados independentes e identicamente distribuídos, mas isso não reflete a realidade, onde as distribuições dos dados podem mudar. A pesquisa abordou nove TFMs diferentes, incluindo TabPFNv2, TabPFNv2.5 e Mitra, e utilizou três conjuntos de dados do mundo real para testar seu desempenho fora do conjunto de dados de treinamento.
